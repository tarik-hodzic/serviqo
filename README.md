# Serviqo

Serviqo is a web-based restaurant management and guest experience platform designed to digitalize and simplify interactions between customers, restaurant staff, and administrators.

The platform uses a QR-based digital system that allows customers to access the restaurant menu directly from their table, place orders, request waiter assistance, and ask for the bill. It also includes table reservations, order management, table management, and administrative features for managing restaurant operations.

The project was developed as a full-stack application with a focus on real-world restaurant workflows, role-based access, and efficient communication between customers and restaurant staff.

## Project Goals

This project was built to:

- Develop a realistic restaurant management platform
- Digitalize traditional restaurant ordering and service workflows
- Implement QR-based menu access and ordering
- Strengthen full-stack web development skills
- Implement authentication and role-based authorization
- Work with RESTful APIs and client-server communication

## Main Features

- User registration and login
- JWT-based authentication
- Role-based access for customers, staff, and administrators
- QR-based digital restaurant menu
- Browse food and beverages
- Menu filtering, including dietary preferences
- Place food and beverage orders directly from the table
- Orders automatically linked to restaurant tables
- Call a waiter directly through the platform
- Request the bill from the table
- Online table reservation system
- Table availability and status management
- Staff table assignments
- Order monitoring and management
- User profile management
- Admin dashboard
- User and role management
- Reservation management
- Restaurant activity monitoring
- Restaurant statistics and analytics

## Local Setup

This project requires a local development environment.

### Requirements

- Node.js
- npm
- MySQL database

### Steps

1. Clone or download the repository
2. Install the required dependencies
3. Create and configure the MySQL database
4. Configure the database connection and required environment variables
5. Start the backend server
6. Start the React frontend
7. Open the application in your browser

## Architecture

- REST-based client-server architecture
- React frontend communicates with the backend through REST API endpoints
- Node.js and Express.js backend handles application logic and API requests
- MySQL database stores users, menu items, orders, reservations, tables, and other restaurant data
- JWT middleware handles authentication and role-based authorization
- Separate functionality for customers, restaurant staff, and administrators

## Security

- Password hashing
- JWT-based authentication
- Expiring authentication tokens
- Role-based authorization
- Password strength validation
- Protection against repeated failed login attempts
- Restricted administrative functionality

## Development Process

Serviqo was developed as a team project following the Software Development Life Cycle (SDLC).

The development process included requirements analysis, system design, implementation, testing, and documentation. Agile practices were used throughout development, with Jira for task management and Git for version control and team collaboration.

## About

This project demonstrates the development of a complete restaurant management system using modern full-stack web technologies.

It focuses on QR-based restaurant services, digital ordering, table reservations, waiter interaction, role-based access control, and restaurant administration through a centralized web platform.

Serviqo was developed for educational purposes and is not intended to represent a production-ready restaurant management system.
